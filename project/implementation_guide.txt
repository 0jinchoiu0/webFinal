一、專案概述

本專案是一個校園心理健康預約系統，包含前端與後端分離架構：
- 後端：Express API + SQLite
- 前端：Vue 3 + Vite
- 功能：諮商師資訊、心理健康文章、服務時段展示、預約表單

此份文件以教學方式說明整體實作流程，讓讀者可以依照步驟自行重現系統。

二、專案架構

請以`project/` 目錄為主要內容：

project/
  server/   # 後端 API 專案
  client/   # 前端 Vue + Vite 專案

三、實作步驟

1. 建立後端專案
   1. 在 `project/server` 內建立 `package.json`，內容包含 `express`、`cors`、`better-sqlite3`。
   2. 建立 `index.js`，使用 Express 建立 API 路由。
   3. 使用 SQLite 檔案資料庫，於啟動時檢查並自動建立資料表。
   4. 設定資料表：`counselors`、`articles`、`sessions`、`appointments`。
   5. 插入模擬資料，包括諮商師名單、文章、服務時段與初始預約紀錄。
   6. 實作 API：
      - `GET /api/status`
      - `GET /api/counselors`
      - `GET /api/articles`
      - `GET /api/sessions`
      - `GET /api/appointments`
      - `GET /api/summary`
      - `POST /api/appointments`
   7. 在 `POST /api/appointments` 中加入欄位驗證，確保：
      - `student_name`、`student_id`、`email`、`appointment_type`、`date`、`topic` 必填
      - `後續治療` 需要選擇 `諮商師` 與 `mode`
      - `初次諮商` 不可選擇 `諮商師`

2. 建立前端專案
   1. 在 `project/client` 內建立 `package.json`，使用 Vue 3 與 Vite。
   2. 建立 `vite.config.js`，設定前端開發伺服器的代理：
      - `/api` 轉發到 `http://localhost:3000`
   3. 建立 `index.html`、`src/main.js`、`src/App.vue`、`src/style.css`。
   4. `App.vue` 內實作 UI 與資料綁定：
      - 顯示諮商師資訊
      - 顯示心理健康文章
      - 顯示服務時段
      - 預約表單包含學生姓名、學生學號、Email、諮商類型、日期、時段、諮商主題
   5. 根據 `appointment_type` 顯示條件欄位：
      - `初次諮商`：顯示文字說明，並禁止選擇諮商師
      - `後續治療`：顯示選擇諮商師與選擇方式（線上/面談）
   6. 在 `onMounted` 內向後端撈取資料，並透過 `fetch` 將表單送出至 `POST /api/appointments`。

四、執行流程

1. 後端安裝套件並啟動
   ```bash
   cd project/server
   npm install
   npm start
   ```

2. 前端安裝套件並啟動
   ```bash
   cd project/client
   npm install
   npm run dev
   ```

3. 開啟瀏覽器
   - 前端預設網址：`http://localhost:5174`
   - 前端會透過代理呼叫後端 API：`http://localhost:3000/api`

六、教學重點

1. 分離前後端架構
   - 前端使用 Vue + Vite，專注畫面與互動。
   - 後端使用 Express + SQLite，專注資料存取與 API。

2. 前端與後端資料串接
   - 前端使用 `fetch` 呼叫後端 API。
   - 後端提供統一 API 路徑，例如 `/api/counselors`、`/api/articles`。
   - Vite proxy 讓開發環境可直接呼叫 `/api`。

3. 表單條件邏輯
   - 根據使用者選擇更新欄位顯示與驗證規則。
   - 在後端也要檢查同樣邏輯，避免前端繞過驗證。

4. SQLite 資料庫初始化
   - 啟動時檢查資料表是否存在，若不存在自動建立。
   - 可依據 `PRAGMA table_info` 動態新增欄位。
   - 使用 `better-sqlite3` 簡化同步查詢。
